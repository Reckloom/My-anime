# FRAME — My Anime

A personal media library for anime, manga, manhwa, light novels, visual novels, movies and series.

Current foundation: cinematic responsive UI, library search/filtering, hierarchical entries, AOT and Steins;Gate starter data, progress, favorites, full editor, local persistence and GitHub build verification.

Next: Supabase authentication, private cloud library, metadata import, release notifications, controlled AI assistant and Android packaging.

Never put a Supabase service-role key in the browser or Android app.
